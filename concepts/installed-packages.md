# A list of how to use some of the packages I've enabled

## glow

Glow lets me view Markdown files in their proper format via the terminal.

```bash
glow ~/path-to-file.md
```

## vifm

vifm is a terminal file-manager inspired by vim which allows me to navigate deep file trees quickly. It uses vim keys and commands such as `:q!` to quit and `TAB` to switch tabs. I find it easier to use `fn + arrows` to navigate.
